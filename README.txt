Bu proje, mini e-ticaret geliştirme sürecinde öğrenilen teknolojilerin verilen bir task üzerinde uygulanması amacıyla geliştirilmiştir. Amaç, öğrenilen araç ve yaklaşımları gerçek bir senaryoda kullanarak pratik kazanmaktır.

Proje kapsamında temel API geliştirme süreçlerinin yanında farklı teknolojiler entegre edilerek sistem genişletilmiştir. Background job işlemleri için Hangfire, arama ve filtreleme işlemleri için Elasticsearch, caching için Redis ve kimlik doğrulama için JWT kullanılmıştır. Ayrıca mail işlemleri ve web scraping gibi ek fonksiyonlar da projeye dahil edilmiştir.

Geliştirme sürecinde katmanlı mimari ve temiz kod prensiplerine dikkat edilmiştir. Bu proje, farklı teknolojilerin birlikte nasıl çalıştığını görmek ve backend geliştirme konusunda pratik kazanmak amacıyla oluşturulmuştur.

Kullanılan Teknolojiler
ASP.NET Core Web API
Entity Framework
JWT Authentication
Hangfire
Redis
Elasticsearch
Mail Service
Web Scraping
MSSQL / PostgreSQL
